## 🧪 Array Test

### 1. Pascal's Triangle

Given an integer `numRows`, generate the first `numRows` rows of Pascal's Triangle.

**Example:**

```text
Input: 5

Output:
[
 [1],
 [1,1],
 [1,2,1],
 [1,3,3,1],
 [1,4,6,4,1]
]
```

---

### 2. Intersection of Two Arrays

Given two integer arrays, return an array containing the **distinct elements that appear in both arrays**.

**Example:**

```text
Input:
nums1 = [1,2,2,1]
nums2 = [2,2]

Output:
[2]
```

---

### 3. Rotate Array

Given an integer array `nums` and an integer `k`, rotate the array to the **right by `k` positions**.

**Example:**

```text
Input:
nums = [1,2,3,4,5,6,7]
k = 3

Output:
[5,6,7,1,2,3,4]
```
