## 💡 **Pro Tips for Infosys**

1. **Infosys LOVES these topics:**
   - Array manipulation (rotations, reversals)
   - String anagrams/palindromes
   - Basic DP (stairs, coin change)
   - Matrix traversal (diagonal, spiral)

2. **Most asked Infosys patterns:**
   - Problem with two arrays
   - String with character counts
   - Find missing/duplicate numbers

3. **Don't ignore edge cases:**
   ```python
   # Always test with:
   - Empty input: [], "", None
   - Single element: [1], "a"
   - Large values: 1000000000
   - Negative numbers: [-5, -2, 0]
   ```
